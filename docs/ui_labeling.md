# Интерфейс для разметки (References)

Веб-интерфейс OASIS (`app.py`, Streamlit) включает вкладку **References**, предназначенную для извлечения и обогащения библиографических ссылок из PDF-обзора и для просмотра/экспорта результата (разметка ссылок).

---

## Запуск

Из корня проекта:

```bash
streamlit run app.py
```

Откроется браузер с приложением; по умолчанию адрес: `http://localhost:8501`.

---

## Вкладки приложения

| Вкладка        | Назначение |
|----------------|------------|
| **Корпус**     | Загрузка PDF обзора в каталог по теме/paper_id. |
| **References** | Разметка ссылок: стадия 1 (извлечение названий), стадия 2 (обогащение), просмотр таблицы, скачивание CSV. |
| **CQs**        | Модуль генерации competency questions (заглушка/инфо). |
| **Онтология**  | Построение и валидация онтологий (заглушка/инфо). |
| **Генерация**  | Генерация обзоров (RAG / ontology-augmented) (заглушка/инфо). |
| **Оценка**     | Оценка качества обзоров и метрик (заглушка/инфо). |
| **Перевод**    | Перевод обзоров (заглушка/инфо). |

## Работа с разметкой ссылок (References)

### Входные данные

- **Тема/каталог** — имя датасета (например, `deep_active_learning`). По нему задаётся путь к данным: `data/<тема>/`.
- **Paper ID** — идентификатор обзора (например, `2405.00334`). PDF обзора должен лежать по пути:  
  `data/<тема>/<paper_id>/review.pdf`.
- Перед запуском этапов интерфейс проверяет наличие этого PDF и показывает сообщение «PDF найден» или «PDF не найден».

### Стадия 1: Извлечь названия

- Кнопка: **«Стадия 1: Извлечь названия»**.
- Действие: из PDF обзора извлекаются ссылки (названия, сырой текст). Результат сохраняется в **`data/<тема>/references_raw.csv`**.
- В интерфейсе отображаются: прогресс, метрики (всего ссылок, с DOI, с arXiv ID, с названием, с ссылкой на статью), таблица строк и кнопка **«Скачать references_raw.csv»**.

### Стадия 2: Обогатить ссылки

- Кнопка: **«Стадия 2: Обогатить ссылки»**.
- Условие: должен существовать файл стадии 1 — `data/<тема>/references_raw.csv`.
- Действие: по каждой ссылке выполняется обогащение (DOI, arXiv, год, venue, авторы, URL статьи, наличие PDF и т.д.). Результат сохраняется в **`data/<тема>/references.csv`**.
- В интерфейсе отображаются: прогресс, метрики обогащённых данных, таблица результатов и кнопка **«Скачать references.csv»**.

### Просмотр уже готовых данных

- Если уже есть **`references.csv`**, при открытии вкладки References (без нажатия кнопок) показываются метрики по этому файлу и таблица обогащённых ссылок; доступна кнопка скачивания CSV.
- Если есть только **`references_raw.csv`** (стадия 2 не запускалась), отображаются данные стадии 1 и кнопка скачивания `references_raw.csv`.

### Экспорт и ручная разметка

- Таблицы в интерфейсе предназначены для просмотра; редактирование ячеек в браузере не предусмотрено.
- Для ручной доработки разметки: скачайте **references.csv** (или **references_raw.csv**), отредактируйте в Excel/CSV-редакторе и при необходимости загрузите файл обратно в `data/<тема>/` с тем же именем. При следующем открытии вкладки отобразятся обновлённые данные.
