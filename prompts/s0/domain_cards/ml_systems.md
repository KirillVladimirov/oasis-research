Domain: **Machine Learning Systems (MLSys)**. MLSys focuses on the end-to-end systems stack that makes modern ML practical at scale: data ingress and preprocessing, distributed training orchestration, efficient inference/serving, and hardware–software co-design for performance and cost. Core elements include ML data pipelines (loading, preprocessing, caching/storage), training systems (resource scheduling, distributed execution, fault tolerance/straggler mitigation, memory management), inference systems (latency/throughput optimization, batching, KV caching), and compiler/kernel-level optimization—often targeting foundation-model workloads alongside "classic" deep learning. A typical loop profiles an end-to-end workload, identifies bottlenecks (I/O, CPU preprocessing stalls, GPU underutilization, communication), applies system interventions (pipeline redesign, caching, sharding/parallelism strategies, scheduling), and re-evaluates under realistic cluster conditions; evaluation emphasizes throughput/latency (including tail), scaling efficiency/goodput, resource utilization, reliability, and cost/energy efficiency.
