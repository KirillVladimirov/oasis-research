Domain: **Graph Neural Network Systems (graph_nn_systems)**. GNN Systems research targets the **systems layer** required to train and serve graph neural networks on large, sparse, and often dynamically changing graphs, where irregular memory access and feature/neighbor retrieval dominate performance. Core elements include graph storage and partitioning (topology + high-dimensional node/edge features), sampling/mini-batching pipelines (neighbor and subgraph sampling) to bound memory, cache and communication optimization for distributed training (mitigating feature-communication bottlenecks, stragglers, and fault tolerance), and hardware/compiler support (GPU kernels, accelerators, compilation and operator fusion) to improve utilization on irregular workloads. A typical loop instruments an end-to-end GNN workload, identifies bottlenecks (I/O/feature fetch, communication, sampling overhead, GPU underutilization), applies system interventions (partition/placement, caching, pipelining, distributed execution strategy), and re-evaluates under realistic scale; evaluation emphasizes step time and throughput, scaling efficiency/goodput, memory footprint, tail latency (for serving), and the accuracy–efficiency trade-off induced by sampling and system approximations.
