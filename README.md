# OASIS

OASIS (Ontology-Augmented Survey Synthesis) — система для генерации научных обзоров с использованием онтологий и графа знаний.

## Исследование

**Тема исследования.**  
Онтологически управляемая генерация обзорных научных текстов большими языковыми моделями.

**Объект исследования.**  
Процессы и системы автоматизированной генерации обзорных научных текстов с использованием больших языковых моделей и внешних корпусов литературы.

**Предмет исследования.**  
Влияние интеграции автоматизированного этапа построения онтологии на основе компетентностных вопросов на качество, ссылочную согласованность и воспроизводимость результатов при фиксированном корпусе источников.

**Цель исследования.**  
Разработка онтологически обогащённого конвейера генерации и его сопоставимое сравнение с базовым подходом LLM с RAG на фиксированном корпусе источников.

**Исследовательский вопрос.**  
Повышает ли включение автоматически построенной онтологии предметной области в конвейер генерации качество результата по сравнению с вариантом без онтологии при фиксированных корпусе источников и параметрах генерации, если качество оценивается через степень согласия ответов на компетентностные вопросы с эталонными формулировками, извлечёнными из референтного обзорного текста?
